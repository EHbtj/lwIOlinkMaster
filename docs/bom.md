## センサーの選定条件

初版ではRevisionID=0x11、周期入力最大32バイト・周期出力0バイト、OPERATE M-sequence code 0/4/5を対象にします。
code 0では入力1～16bit、code 4では入力3～32バイト、code 5ではOD幅2バイトを使用します。
PDを持たないType 0機器にも接続できますが、測定値試験には入力PDを持つ機器を選んでください。
Type 1、OD幅8/32バイト、周期出力を必要とする機器は初版で拒否されます。
COM速度、MinCycleTime、データ形式、書換可能なIndex/Subindexをメーカー資料から確認してから購入します。
設定試験には、機能動作を変えないユーザータグなど、書戻し可能な項目を優先します。
