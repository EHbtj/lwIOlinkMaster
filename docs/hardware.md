# TIOL1123評価基板との接続

対象はTIOX1X2XEVMに標準実装されるTIOL1123です。以下はTI SLLU344の信号名を使います。
ヘッダーの向きは実物のシルクと回路図で照合してください。
[TIジャンパー表](https://www.ti.com/document-viewer/lit/html/SLLU344/GUID-D9E648E8-35B5-426F-B9CF-E539FCBF7898)、
[TIOL112データシート](https://www.ti.com/lit/ds/symlink/tiol112.pdf)。

## MCUとPHY

| EVM側の信号 | XIAO ESP32C3 | ESP32-S3-DevKitC-1 | 方向 |
| --- | --- | --- | --- |
| TX（J10信号） | D6 / GPIO21 | GPIO17 | MCU UART1 TX → PHY TX入力 |
| RX（J10信号） | D7 / GPIO20 | GPIO18 | PHY RX出力 → MCU UART1 RX |
| EN（J10信号） | D2 / GPIO4 | GPIO16 | MCU RTS → PHY EN |
| nFAULT（J11信号） | D3 / GPIO5 | GPIO15 | PHY → MCU、3.3Vプルアップ |
| GND | GND | GND | 24V電源マイナスと共通 |
| WAKE | 未接続 | 未接続 | この試作では使用しない |
| VCC / VCC_LP / 3V3_LP / 5V_LP | 未接続 | 未接続 | 電源出力を相互接続しない |

TX/RXはトランシーバーの信号名と対応させます。UART機器同士のように交差させません。
ピン番号はスケッチ先頭の`pins()`で変更できます。USBピンと起動ストラップ端子は避けてください。
ドライバーはUART1を占有し、UART0/USBからのログをIO-Link線に流しません。

## EVMジャンパー

| ジャンパー | 設定 | 用途 |
| --- | --- | --- |
| J3 | ショートプラグを外す。ENはMCUに接続 | MCUから送信イネーブルを制御 |
| J4 | GND | TIOL1123のマスターモードを有効化 |
| J5 | プラグを外す | 未使用のMCU供給レールを切り離す |
| J6 | DO_EN–GND | 使用しないTIOS1023の出力を停止 |
| J7 | 外部低電圧電源を接続しない | TIOL1123の内蔵3.3V LDOを使用 |
| J8 | 変更不要 | TIOS1023は無効化して使用しない |
| J9 | 全プラグを外す | VCC_EXTとLDO/MCUレールを接続しない |
| J10 / J11 | 上表の信号線だけを接続 | 電源信号への誤接続を避ける |

J4=GNDではCQ電流制限が少なくとも500mAとなり、電流異常通知・出力遮断・自動復帰の一部は無効です。
`nFAULT`を過電流検出の代わりにはできません。ソフトはこの端子のLowを汎用PHY異常として扱い、原因を断定しません。

## 電源とセンサー

- MCU: USBから給電。TIOL1123のLDOは最大20mAであり、ESP32の給電には使用しない。
- EVM: 電流制限付き外部24V電源をJ1のL+_24V/GNDへ接続。
- センサー: M12 Class Aならpin 1=L+、pin 3=L−、pin 4=C/Q。pin 2のDOは使わない。
- CQはJ1のCQまたはJ2のM12に接続する。24VやCQをMCU端子に直接接続しない。
- MCU GND、EVM GND、24V電源マイナスを接続する非絶縁の卓上構成。
- 外部電源の電流制限値は、センサーの消費電流と起動突入、EVM消費を確認して決める。
  Wake-upのCQ電流パルスを電源が支えられることを実測する。

初回は電源を切った状態でジャンパーと配線を確認し、センサー未接続でENがLowであることと、
EVMのロジック出力が3.3Vであることを確認してから接続します。

## 起動波形

TIOL112はTX/RXがC/Qに対して反転します。RXで観測した現在値に対してTXを反転させ、
ENを約80µs有効にしてWake-up要求を出します。UART送受信中はIDFの半二重RTS制御を使います。
GPIO操作と割込み抑止によるパルス幅は未実測です。許容範囲75～85µsとCOM3の送受信切替を
オシロスコープで確認するまで実機対応済みとは扱いません。
